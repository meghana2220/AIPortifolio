# Meghana Agarwal — Professional Developer Portfolio

A modern, responsive portfolio website showcasing skills as a Frontend Developer, Backend Developer, and Java Trainer. Built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## 🚀 Live Demo & Repository
- **Repository:** [https://github.com/meghana2220/AIPortifolio](https://github.com/meghana2220/AIPortifolio)

## 🛠️ Tech Stack
- **HTML5:** Semantic markup, accessibility, and structured content.
- **CSS3:** Custom design system (tokens/variables), Flexbox, CSS Grid, smooth transitions, ambient glowing effects, and responsive breakpoints.
- **JavaScript (ES6+):** Zero-dependency vanilla JS for scrollspy navigation, scroll-reveal animations, 3D card tilt physics, universal toast notifications, click-to-copy, and form validation.

## 📁 Project Structure
```text
PortifolioDemo/
├── index.html        # Main semantic markup and page structure
├── style.css         # Complete design system and styling
├── script.js         # Interactive features and animations
└── README.md         # Project documentation
```

## ✨ Features
- **Hero Section:** Ambient purple gradient glow, intro badge, calls to action, and profile card with floating mentorship badge.
- **About Me:** Professional background, key highlights, and career summary.
- **Technical Skills:** 4 categorized skill cards across Frontend, Backend, Databases, and Tools.
- **Professional Experience:** Timeline card detailing Java Trainer experience at Teks Academy.
- **Education:** Academic qualifications (MCA, B.Sc., MPC, Class 10).
- **Featured Projects:** 6 project cards with tech tags, key features, and GitHub/project links.
- **What I Do:** Frontend and Backend development overview.
- **Contact & Feedback:** Interactive contact cards with click-to-copy, toast alerts, and a client-validated form.
- **Back to Top:** Floating smooth-scroll return button.
